# Computational Data and GAP Codes

This repository contains the GAP codes and related computational data accompanying the manuscript:

**R. K. Choudhary, H. Kishnani, and A. Singh,** *2-generation of Chevalley Lie Algebras over Finite Fields.*

The manuscript is available as a preprint on [arXiv:2610.35537](https://doi.org/10.48550/arXiv.2610.35537).

The codes provided in this repository are written in **GAP** (Groups, Algorithms, Programming) and are used to perform and verify the computational calculations appearing in the manuscript.

---

### `G2-2-Generation.g`

This GAP script verifies the 2-generation of the split simple Chevalley Lie algebra of type G_2 over the finite fields F_q, for q=5,7, and 11.

It provides explicit pairs of generators for the corresponding Lie algebras.

---

### `F4-Positive-Roots.g`

This GAP script performs computations related to the root system of type \(F_4\), including:

- Computation of positive roots.
- Determination of distinct linear factors.
- Other related computations used in the manuscript.

---

### Reproducing the computations

To reproduce the computations, install GAP, load the corresponding `.g` file, and execute the commands provided in the script.

The codes are provided to facilitate the verification and reproducibility of the computational results in the manuscript.
